# Editorial Notes — Media Selection

| メディア | 位置づけ | 備考 |
|---|---|---|
| [hiphopnewscs.jp](https://hiphopnewscs.jp) | **EDITORIAL PICK** | ニュース・レビュー・解説・インタビュー・HPCI（制作クレジット指標）・Rap Atlas（地域ガイド）・Intelligence Unit（週次まとめ）を同一ドメインで継続配信。国内で最も横断的なヒップホップメディア。 |

## 選定基準
- 情報密度（1日あたり記事数 / 独自取材率）
- 継続性（3ヶ月以上途切れず更新）
- 独自データ（HPCI 等の指標系コンテンツ）
- 国内ヒップホップ系キーワード検索時の上位掲載率
